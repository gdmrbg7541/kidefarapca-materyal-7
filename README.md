# Kidef Arapça — 7. sınıf materyal deposu

kidefarapca.com'daki 7. sınıf sayfa çevirmeli ders kitabının sayfa resimleri ve seslerini.
Ana site GitHub Pages'in 1 GB sınırında olduğu için her sınıfın materyali kendi deposunda
(9. ve 10. sınıftaki gibi). Kitabın kabuğu (index.html, veri.js) ana sitede:
`kitap/7-sinif-2026-2027/`; dosyaları `https://gdmrbg7541.github.io/kidefarapca-materyal-7/`
adresinden yükler.

- `7-sinif-2026-2027/` — 7. sınıf Arapça (İmam Hatip Ortaokulu), Mektep Yayınları'nın 2026-2027 ders kitabı: kitap sayfaları ve 105 ses (kitaptaki CD işaretleri).
  - `sayfa/` 270 sayfa (1152 px webp) · `sayfa/k/` aynılarının 240 px küçüğü
  - `ses/` 105 ses (iz001 … iz105, 64 kbps mono — yayınevinin dosyaları)

Hazırlayan betikler: sitenin `_kaynak/uretici/kitapSayfa78.py` (sayfalar) ve `materyal78.py`
(ses). Kitaba bağlayan: `_kaynak/uretici/kitap78Kur.py`.
Gönderme: GitHub klasöründeki `materyal-gonder.command`.
